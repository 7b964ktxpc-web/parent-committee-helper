# Помощник родительского комитета

Личный чат-помощник для одного пользователя. Помогает писать и редактировать сообщения в родительский чат, отвечать на возражения, мотивировать родителей, готовить сборы и снимать конфликты.

## Запуск локально

```bash
cd "C:\Users\Дмитрий\parent-committee-helper"
npm install
npm start
```

Откройте http://localhost:3000

## Деплой на Vercel

### Способ 1: через Vercel CLI

```bash
npm i -g vercel
vercel login
vercel
```

### Способ 2: через GitHub

1. Создайте репозиторий на GitHub.
2. Загрузите файлы проекта.
3. На https://vercel.com/new выберите этот репозиторий.
4. В разделе **Environment Variables** добавьте:
   - `OPENAI_API_KEY` — ваш ключ OpenAI.
   - `OPENAI_MODEL` — (опционально) модель, по умолчанию `gpt-4o-mini`.
5. Нажмите **Deploy**.

Vercel сам подхватит `vercel.json` и развернёт приложение.

### Что внутри

- `server.js` — Express-приложение, локальный запуск и экспорт для Vercel.
- `api/index.js` — serverless-обёртка для Vercel (`serverless-http`).
- `vercel.json` — маршрутизация: `/api/*` и всё остальное идут через один serverless-функциональный обработчик.
- `public/` — статика: `index.html`, `styles.css`, `app.js`.

## Режимы работы

- **Без API-ключа** — работает встроенный локальный режим (простые эвристические ответы, чтобы проверить UX).
- **С OpenAI API** — задайте переменную окружения `OPENAI_API_KEY` (опционально `OPENAI_MODEL`, по умолчанию `gpt-4o-mini`).

```bash
# PowerShell
$env:OPENAI_API_KEY = "sk-..."
npm start
```

Ключ хранится только на сервере, в браузер не попадает.

## Какая модель

По умолчанию: **OpenAI `gpt-4o-mini`** (или любая другая OpenAI-совместимая модель через `OPENAI_MODEL`).

Это можно изменить переменной окружения `OPENAI_MODEL` на любую доступную у вас модель (например, `gpt-4o`, `gpt-4-turbo`, `o3-mini` и т. д.). Без ключа приложение работает в локальном режиме на простых эвристиках.

## Что умеет

- Первый запуск с аккуратным экраном настройки (имя, имя помощника, группа, сад, роль, стиль мульти-чипами, контекст группы).
- Чат в стиле мессенджера, индикатор «печатает…», кнопка «Копировать» у готового текста.
- Быстрые действия под полем ввода: «Написать сообщение», «Ответить», «Сбор денег», «Поддержать», «Голосование».
- Настройки (боковая панель на десктопе / bottom sheet на мобильном): редактирование профиля, стиля, контекста; сброс настроек; очистка переписки.
- Все данные (профиль и история) сохраняются в `localStorage`.
- Мобильная адаптация, поддержка экранной клавиатуры (`100dvh`, `env(safe-area-inset-bottom)`).
- `Enter` — отправка, `Shift+Enter` — перенос.
- Человеческие сообщения об ошибках, без технических логов в UI.
